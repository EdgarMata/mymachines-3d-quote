## Known security findings
After local MM-005: nested public response allowlists protect HTTP output, including raw slicing costs, profiles, operational flags and unknown internal fields. Geometry validation cannot guarantee topology repair, printability or bounded CPU time. Heavy work runs in bounded threads with fail-fast admission and a slicer deadline, but there is no hard global request/geometry deadline or rate limiting. API diagnostics omit raw exceptions and submitted validation values; infrastructure access logs can still contain IPs/query strings. Public labels, compatibility and final prices are intentional disclosures. Quantity is bounded before geometry work. Shared workspaces preserve immediate cleanup and recover recognized unlocked orphans; unrecognized/legacy or incomplete-metadata directories require explicit operator review. This is not a disk quota or secure-erasure guarantee. Private commercial configuration (MM-007) and deployment/load validation remain pending. CORS and disabling docs are not authentication.
